# iOS スタンバイモード 仕様の洗い出しと Web 版での再現方針

iOS 17 で追加された「スタンバイ（StandBy）」の仕様を洗い出し、本アプリ（ブラウザで動く Web アプリ）でどう再現しているかをまとめたものです。

凡例: ✅ 再現 / 🔶 代替手段で再現 / ❌ Web の制約で再現不可

## 1. 起動・終了条件

| iOS の仕様 | Web 版 | 実装内容 |
| --- | --- | --- |
| iPhone が **充電中** で **横向き** かつ **ロック中・静止** の時に自動で表示 | 🔶 | Battery Status API（`navigator.getBattery()`）の `charging` と `matchMedia('(orientation: landscape)')` で判定し自動開始（`src/rules.ts` の `shouldAutoStart`） |
| 充電状態が取得できない端末 | 🔶 | iOS Safari / Firefox は Battery Status API 非対応のため、横向きだけを条件にする |
| 縦向きに戻す・充電をやめると終了 | ✅ | `shouldAutoExit`。手動で開始した場合は充電をやめても継続 |
| 設定でスタンバイ自体をオフにできる | ✅ | 設定「自動で開始」 |
| ロック中であることが条件 | ❌ | Web ページは端末のロック状態を扱えない。アプリ（ブラウザ）を前面に開いたまま置く運用 |
| MagSafe 充電器ごとに最後に使った画面を記憶 | 🔶 | 充電器の識別は不可。最後に表示していた画面・文字盤を `localStorage` に保存して復元 |

## 2. 画面構成と操作

| iOS の仕様 | Web 版 | 実装内容 |
| --- | --- | --- |
| 3 つの画面: **ウィジェット / 写真 / 時計** を左右スワイプで切り替え | ✅ | `src/standby.ts`。並び順も iOS と同じ（左からウィジェット・写真・時計） |
| 各画面内は上下スワイプで切り替え | ✅ | ウィジェット: 左右それぞれのスタック、写真: 次/前の写真、時計: 文字盤 |
| 長押しで編集モード | ✅ | 長押し（550ms）で編集シートを表示（`src/gestures.ts`） |
| 切り替え時のページインジケーター | ✅ | スワイプ時のみ点で現在位置を表示 |
| タップで画面を起こす | ✅ | 消灯中はタップで復帰 |

## 3. ウィジェット画面

| iOS の仕様 | Web 版 | 実装内容 |
| --- | --- | --- |
| 左右 2 つの **スマートスタック** | ✅ | `src/views/widgetsView.ts` |
| 上下スワイプでスタック内のウィジェットを切り替え | ✅ | タッチした側のスタックだけ切り替わる |
| **スマートローテーション**（状況に応じて自動で切り替え） | 🔶 | 端末の利用状況は取れないため 10 分ごとに次のウィジェットへ切り替え（オン/オフ可） |
| 既定は 左: 時計 / 右: カレンダー | ✅ | 既定値を同じ構成に設定 |
| 編集モードでウィジェットの追加・削除 | ✅ | 長押し → 各スタックのウィジェットをオン/オフ |
| 利用可能なウィジェット | 🔶 | 時計（アナログ/デジタル）・カレンダー（月）・日付・世界時計・バッテリー・天気。天気は位置情報 + Open-Meteo（設定でオンにした場合のみ通信） |
| サードパーティアプリのウィジェット、カレンダーの予定・リマインダー・ホーム | ❌ | 端末のアプリ・個人データには Web からアクセスできない |

## 4. 写真画面

| iOS の仕様 | Web 版 | 実装内容 |
| --- | --- | --- |
| 写真ライブラリの「おすすめ写真」をスライドショー | 🔶 | 写真ライブラリには直接アクセスできないため、ユーザーが選んだ写真を端末内の IndexedDB に保存して表示（外部送信なし） |
| 写真の上に時刻と日付を表示 | ✅ | 左上に日付と時刻 |
| 上下スワイプでアルバム/写真を切り替え | 🔶 | 次/前の写真に切り替え |
| 一定時間ごとに写真が切り替わる | ✅ | 10 秒〜5 分で設定可。クロスフェード + ゆっくりズーム |
| 編集で表示するアルバムを選ぶ | 🔶 | 長押し → 写真の追加・全削除 |

## 5. 時計画面（文字盤）

iOS 17 の 5 種類をすべて再現しています（`src/clock/faces.ts`）。

| 文字盤 | iOS の特徴 | Web 版 |
| --- | --- | --- |
| アナログ | 数字入りの大きなアナログ時計。秒針の色を変更可 | ✅ 秒針・中心の色を 9 色から選択 |
| デジタル | 画面いっぱいの数字と日付。色を変更可 | ✅ |
| ワールド | 点描の世界地図に現在地と時刻。昼夜で地図の明るさが変わる | ✅ 太陽位置を計算して昼の地域を明るく表示。現在地はタイムゾーンから推定（位置情報の許可不要） |
| ソーラー | 太陽の位置に合わせて背景のグラデーションが変化 | ✅ 太陽高度（NOAA 簡易式）から空の色と太陽の光の位置を計算 |
| フロート | 丸みのある大きな数字がゆらゆら動く。色を変更可 | ✅ |

12 時間表示 / 24 時間表示の切り替えにも対応しています。

## 6. ディスプレイ・夜間の挙動

| iOS の仕様 | Web 版 | 実装内容 |
| --- | --- | --- |
| **常時表示**（Always-On 対応機種は画面を点けたまま） | 🔶 | Screen Wake Lock API で自動ロックを防止（iOS Safari 16.4+ / Android Chrome 対応）。タブが裏に回ると解除されるため、表示に戻ったら再取得 |
| 常時表示非対応機種はしばらくすると消灯し、タップで復帰 | ✅ | 設定「自動で画面を消す」（20 秒〜15 分）。黒画面にして OLED では実質消灯 |
| **ナイトモード**: 暗い部屋では赤一色の表示 | 🔶 | 照度センサー（Generic Sensor API の `AmbientLightSensor`）が使えればそれで判定、使えなければ指定時刻（既定 22:00〜6:00）で自動切り替え。手動でオン/オフも可 |
| **モーションで起動**: 夜間に端末の動きを検知して表示 | ✅ | DeviceMotion で加速度の変化を検知して復帰（iOS Safari ではユーザー操作時に許可を取得） |
| 焼き付き防止 | ✅ | 表示位置を毎分数 px ずらす |

## 7. 通知・その他

| iOS の仕様 | Web 版 | 備考 |
| --- | --- | --- |
| 通知を大きく表示（設定でプレビューをタップ時のみに） | ❌ | 他アプリの通知は Web から読めない |
| ライブアクティビティ（タイマー、配達状況など）を全画面表示 | ❌ | 同上 |
| Siri の応答を全画面表示 | ❌ | 同上 |
| 着信時の全画面表示 | ❌ | 同上 |

## 8. 対応環境と使い方のポイント

- **Android（Chrome / Edge）**: 充電状態の検知・Wake Lock・全画面・横向き固定にすべて対応。最も iOS に近い動作になります。
- **iPhone / iPad（Safari）**: 充電状態が取得できないため「横向き」で自動開始します。ホーム画面に追加（PWA）すると全画面で表示できます。
- **その他**: 横向き判定と時計表示はすべてのモダンブラウザで動作します。
- 自動開始では全画面にできない（ブラウザの制約でユーザー操作が必要）ため、スタンバイ画面を 1 回タップすると全画面になります。
- 一度読み込めば Service Worker によりオフラインでも起動できます。
